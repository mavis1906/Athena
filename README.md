# Athena

Athena is a social problem-solving platform where people from different fields can share real-world problems, contribute ideas, discuss solutions, and learn from one another.

The platform is designed around the idea that knowledge becomes more useful when people can bring their different experiences and expertise together.

## Version 1

Athena V1 focuses on building the core problem-solving community.

### Features

- User registration and login
- Secure password hashing and authentication
- User fields and professional roles
- General problem feed
- Role-specific problem feed
- Problem creation
- Problem descriptions with image attachments
- Problem discussions through comments
- Problem likes
- Problem completion
- Solved problems section
- User logout
- SQLite database
- Local image storage
